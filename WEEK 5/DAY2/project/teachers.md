# Nakuru School Attendance Monitor (Teacher & Principal Edition)

A self-service Streamlit dashboard for reviewing attendance by class and date range. Principals can view all classes, while teachers can select a class, review its attendance, and download the filtered records as a CSV.

## Features

- **CSV Upload:** Drag and drop an attendance CSV in the sidebar.
- **Class Filter:** Select **All Classes** for a school-wide view or choose a specific class.
- **Date Range Picker:** Filter records between selected dates; the initial range defaults to approximately the last 30 days.
- **Attendance Metrics:** See the overall attendance rate. With all classes selected, the dashboard also shows the best- and worst-attending classes; for one class, it shows that class's best and lowest attendance days.
- **Side-by-Side Charts:** Compare daily attendance trends with period attendance rates by class.
- **Filtered CSV Download:** Export the records matching the selected class and date range.

## Project Structure

- `teachers.py` — Streamlit application for uploading, filtering, reviewing, and exporting attendance.
- `nakuru_attendance.csv` — Default sample dataset; generated by the app if it is missing.
- `teachers.md` — Project documentation.

## Expected CSV Format

The uploaded CSV must contain these four columns:

| Column Name | Type | Description | Example |
| --- | --- | --- | --- |
| `date` | Date (`YYYY-MM-DD`) | Date of the daily roll call | `2026-11-26` |
| `class_name` | Text | Class or stream name | `Form 2 Green` |
| `students_present` | Integer recommended | Students present on that date | `36` |
| `students_total` | Integer recommended | Total students enrolled in the class | `46` |

Example:

```csv
date,class_name,students_present,students_total
2026-11-26,Form 1 East,42,44
2026-11-26,Form 2 North,38,42
2026-11-26,Form 3 West,34,40
2026-11-26,Form 4 South,35,38
2026-11-26,Grade 8 Central,40,45
```

## What Each Dashboard Section Shows & Why It Matters

### 1. Dataset and Filters

The dashboard identifies the active CSV, then provides a class selector and date range picker. **All Classes** shows every class in the active dataset; selecting a class narrows the dashboard to that class.

### 2. Attendance Metrics

The overall rate is calculated from total students present divided by total student-days in the filtered records. For an all-class view, the other metrics identify the best- and worst-attending classes. For a single-class view, they identify the best and lowest attendance days.

### 3. Daily Attendance Trend

The line chart shows daily attendance percentages for the selected date range. In the all-class view, each class appears as a separate line; when one class is selected, the chart shows that class.

### 4. Attendance Rate by Class

The bar chart beside the daily trend compares each selected class's weighted attendance rate across the filtered date range. When a single class is selected, it shows that class's rate.

### 5. Filtered Records and Download

The table displays the records matching the selected filters, including the calculated attendance rate. Use **Download Filtered CSV** to export this same filtered data. The export includes `date`, `class_name`, `students_present`, `students_total`, and `attendance_rate`.

## Data Handling and Access Note

The app checks that required columns are present, parses dates and numeric counts, removes invalid rows, excludes rows where `students_total` is zero or less, and limits `students_present` to the range from zero to `students_total`.

The class selector is a data filter, not an account or permission system. It does not authenticate users or restrict a teacher to an assigned class. Add appropriate access controls before using it where class-level privacy is required.

If `nakuru_attendance.csv` is missing, the app generates deterministic sample data for 45 school days across five classes. Uploaded files replace the default data for the current view.

## Installation & Setup

### Prerequisites

- Python 3 installed on your system.
- Streamlit, Pandas, and NumPy.

Install the packages:

```powershell
python -m pip install streamlit pandas numpy
```

## Usage

Open a terminal in the project directory and run:

```powershell
streamlit run teachers.py
```

Upload a CSV from the sidebar, or use `nakuru_attendance.csv` as the default dataset. Choose **All Classes** or a class, select the date range, review the metrics and side-by-side charts, and download the filtered report.
