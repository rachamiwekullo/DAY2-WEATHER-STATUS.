# Nakuru School Attendance Monitor

A mobile- and laptop-friendly Streamlit dashboard that helps a school principal monitor daily student attendance, compare class performance, and identify attendance dips over a selected date range without opening Excel.

## Features

- **CSV Data Loading:** Upload an attendance CSV or use generated sample data.
- **Date Range Filtering:** Review a selected period, defaulting to approximately the last 30 calendar days.
- **Attendance KPIs:** See the overall rate and the best- and worst-attending classes for the selected period.
- **Grouped Daily Bar Chart:** Compare each class's attendance rate side by side for each date.
- **Class Summary:** Review student-present totals, student-days, and attendance rates by class.

## Project Structure

- `attendance.py` — Loads and validates attendance data, displays the dashboard, and generates sample data when needed.
- `nakuru_attendance.csv` — Default data file; generated by the app if it does not exist.
- `attendance.md` — Project and data documentation.

## Expected CSV Format

The app expects a CSV containing these four columns:

| Column Name | Type | Description | Example |
| --- | --- | --- | --- |
| `date` | Date (`YYYY-MM-DD`) | Date of the daily roll call | `2026-11-26` |
| `class_name` | Text | Name or stream of the class | `Form 3 West` |
| `students_present` | Number (integer recommended) | Students present on that date | `34` |
| `students_total` | Number (integer recommended) | Total enrolled or expected students | `40` |

Example rows:

```csv
date,class_name,students_present,students_total
2026-11-24,Form 1 East,42,44
2026-11-24,Form 2 North,38,42
2026-11-24,Form 3 West,34,40
2026-11-24,Form 4 South,35,38
2026-11-24,Grade 8 Central,40,45
```

Provide one row per class per date. Five class records for a date produce five side-by-side bars for that day; missing class/date records will not have a bar.

## What Each Dashboard Section Shows & Why the Principal Cares

### 1. Overall Attendance Rate

The overall rate is calculated across all selected records:

```text
sum(students_present) / sum(students_total) * 100
```

It gives the principal a period-wide view of attendance, weighted by class size and the number of school days recorded.

### 2. Best- and Worst-Attending Classes

The dashboard totals students present and student-days for each class in the selected date range, then ranks class attendance rates. These figures help the principal identify classes to recognize and classes that may need follow-up.

### 3. Daily Attendance by Class (Grouped Bar Chart)

Each date has a separate bar for every class with a record for that date. Comparing the bars makes daily differences and possible dips easier to spot.

### 4. Attendance by Class Table

The table lists total students present, student-days, and attendance rate for each class over the selected range. It provides the totals behind the class comparison.

## Findings Summary

When no default CSV is present, the app generates deterministic sample data for 45 weekdays across five classes. The sample includes a simulated decline for Form 3 West near the end of the period; this is demonstration data, not a finding about a real school.

Rows with invalid dates or non-numeric attendance counts are excluded. Rows with `students_total` of zero or less are also excluded. The app reports an error if required columns are missing.

## Installation & Setup

### Prerequisites

- Python 3 installed on your system.
- Pandas, NumPy, and Streamlit.

Install the required packages:

```powershell
python -m pip install pandas numpy streamlit
```

## Usage

Open a terminal in the project directory and run:

```powershell
streamlit run attendance.py
```

The dashboard opens in your browser. Upload a CSV using the sidebar, or leave it empty to load `nakuru_attendance.csv`. If the default file does not exist, the app creates it with sample attendance records.

## Dashboard Overview

```text
Date Range Filter
Overall Attendance Rate | Best-Attending Class | Worst-Attending Class
Daily Attendance Rate by Class (grouped bar chart)

```
