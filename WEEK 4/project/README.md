# Kisumu Fish Market Sponsor Sales Analysis (`v1.0`)

A Python, SQLite, and `pandas` analysis package that summarizes three months of fish-market sales for a Kisumu County government sponsor review. It reports leading vendors, compares retail and wholesale sales, tracks monthly revenue, and creates a three-panel chart and executive sponsor report.

> **Data note:** The script currently generates 54 reproducible sample transactions with NumPy's fixed random seed. These are demonstration data, not verified market records. Replace and validate the sample data before using the findings in an official sponsor report.

## Key Findings

- **Leading vendors:** Dunga Pier Traders leads with **KES 222,211.20** in revenue across **740.7 kg**, followed by Akinyi Lake Catch (**KES 218,876.50**) and Otieno Tilapia Hub (**KES 111,558.80**).
- **Retail and wholesale:** Retail has a higher average price per kilogram (**KES 563.00** versus **KES 270.58** for wholesale), while wholesale contributes more total revenue (**KES 720,831.80** versus **KES 197,549.10**) through larger sales volumes.
- **Monthly trend:** Revenue rises from **KES 224,927.00** in August to **KES 314,919.30** in September and **KES 378,534.60** in October 2026.

## Analysis

The script creates a `fish_sales` SQLite table and runs three Pandas SQL reports:

1. **Top three vendors by revenue:** Transaction count, kilograms sold, and total sales value.
2. **Retail vs. wholesale:** Transaction count, kilograms sold, average price per kilogram, weighted revenue per kilogram, and total revenue.
3. **Monthly trend:** Transaction count, kilograms sold, and revenue by month.

It also generates a three-panel chart and a short sponsor report with the findings and a recommendation to prioritize cold storage, digital weighing scales, and clean stall upgrades.

## Setup & Usage

### Prerequisites

- Python 3.9+.
- SQLite, included with Python.
- `pandas`, `numpy`, and `matplotlib`.

Install the required packages:

```bash
python -m pip install pandas numpy matplotlib
```

Run the analysis from the project directory:

```bash
python kisumu_fish_market_analysis.py
```

The script seeds the sample database, prints all three report tables, saves the chart as `kisumu_fish_market_report.png`, and writes `kisumu_fish_market_sponsor_report.md`.

> **Important:** Running the script drops and recreates the `fish_sales` table in `kisumu_fish_market.db`, replacing its contents with generated sample transactions. Back up any database data you need before running it.
