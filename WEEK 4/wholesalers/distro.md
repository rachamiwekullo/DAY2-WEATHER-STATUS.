# Nairobi Wholesale Distributor Monday Sales Report

A lightweight Python and SQLite reporting script that replaces a manual Monday morning Excel workflow with an automated report answering five core weekly sales questions.

## Features

- **SQLite Orders Database:** Creates `distributor_orders.db` with an `orders` table containing order, customer, county, product, quantity, unit price, date, and status details.
- **Sample Wholesale Data:** Seeds 22 example transactions across seven Kenyan counties.
- **Automated Five-Question SQL Report:** Uses `pandas.read_sql_query` to report Mombasa orders, the ten highest-value orders, county revenue, high-value pending orders, and the three best-selling products.
- **Cancellation Handling:** Excludes cancelled orders from county revenue and best-selling product totals.

## Project Structure

- `distro.py`                 # Creates the SQLite database, seeds sample orders, and runs the five reports
- `distributor_orders.db`     # SQLite database generated by the script
- `distro.md`                 # Project documentation

## Weekly Sales Questions

| Report | What it shows |
| :--- | :--- |
| Mombasa orders | All orders from Mombasa county, including their status and calculated value |
| Top 10 orders | The ten orders with the highest quantity-times-unit-price value |
| Revenue per county | Order count and total revenue by county, excluding cancelled orders |
| High-value pending orders | Pending orders worth more than KES 50,000 |
| Best-selling products | The three products with the highest units sold, excluding cancelled orders |

## Recommendation

Prioritize follow-up on pending orders valued above KES 50,000, and use the county revenue and product rankings to guide weekly sales and stock discussions. Confirm order status before treating an order value as realized revenue.

## Findings Summary

The sample dataset contains 22 wholesale orders across seven counties. The report separates operational follow-up from sales performance: it identifies pending high-value orders, summarizes county revenue without cancelled orders, and ranks products by units sold while excluding cancellations. The top-10 order-value report lists orders regardless of status, so use its status column when interpreting those results.

## Installation & Setup

### Prerequisites

- Python 3.7+ installed on your system.
- SQLite is included with Python; no separate database installation is required.

### Steps

Open a terminal in the project directory and install Pandas:

```powershell
python -m pip install pandas
```

## Usage

1. Open a terminal in the project directory.
2. Run the report script:

```powershell
python distro.py
```

The script creates or replaces the `orders` table in `distributor_orders.db`, inserts the 22 sample orders, then prints all five reports in the terminal. Running it again resets that table to the bundled sample data.
